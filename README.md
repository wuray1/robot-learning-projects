# 真实机械臂上的自主操作与避障

吴睿的真机研究展示页，介绍依据 VLSA-RL 与 CRISP 研究思路开展的 Rizon 4 实验。

页面包含静态障碍下的残差强化学习、动态假手避障，以及 VR 示教、数据处理和 VLA 微调过程。

## 浏览与本地预览

这是纯静态网站。使用 Python 3 启动本地预览：

```bash
python3 -m http.server 8000
```

在浏览器打开 http://localhost:8000 。修改 `index.html` 中的文字，`portfolio.css` 中的样式；视频与图片位于 `assets/`。

## 发布范围

本仓库只包含展示页及其引用的媒体文件，不包含机器人控制程序、模型权重或完整原始实验数据。论文作者和开源工具来源列在页面中。
